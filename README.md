# Shri-Mrikulaji-Ayurvedic-Clinic
A full-stack web application developed for an Ayurvedic clinic to streamline patient engagement, appointment booking, product management, and content management. The platform includes role-based access control, WhatsApp notifications, secure authentication, and a comprehensive admin dashboard for managing clinic operations.

---

## 🚀 Features

### 🔐 Authentication & Authorization
- Secure login and registration
- Role-based access control (Admin, Doctor, Patient)
- Protected routes and secure session management

### 📅 Appointment Management
- Online appointment booking
- Appointment scheduling and management
- Doctor-wise appointment tracking

### 💬 WhatsApp Integration
- Automated WhatsApp notifications
- Appointment confirmations and updates
- Improved patient communication

### 👨‍⚕️ Doctor Management
- Manage doctor profiles
- Display doctor details and specialties
- Schedule management

### 🛍️ Product Management
- Add, update, hide, and manage Ayurvedic products
- Dynamic product listings
- Database-driven product management

### 📝 Blog Management
- Create, edit, and manage blog posts
- Dynamic content updates from admin dashboard

### 🛠️ Admin Dashboard
- Manage doctors, products, blogs, and appointments
- Centralized clinic administration
- Real-time content management

### 📱 Responsive Design
- Mobile-friendly user interface
- Optimized for desktop, tablet, and mobile devices

---

## 🧑‍💻 Tech Stack

- **Frontend:** React.js, JavaScript, HTML, CSS, Tailwind CSS
- **Database:** Supabase
- **Authentication:** Supabase Auth
- **Messaging:** WhatsApp API
- **File Storage:** Supabase Storage

## ⚙️ Installation & Setup

```bash
# Clone the repository
git clone https://github.com/minnoli-madhyan/Shri-Mrikulaji-Ayurvedic-Clinic.git

# Navigate to project folder
cd Shri-Mrikulaji-Ayurvedic-Clinic

# Install dependencies
npm install

# Start development server
npm run dev
```
